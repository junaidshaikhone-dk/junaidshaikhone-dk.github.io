# Junaid Shaikh — Doctoral Portfolio

A GitHub Pages-ready academic portfolio for Junaid Shaikh, doctoral researcher in Health Informatics at Rutgers University.

## Publish with GitHub Pages

1. Create a new GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. Your site will be available at `https://YOUR-USERNAME.github.io/`.

## Personalize

Search `index.html` for:
- GitHub
- LinkedIn
- your-email@example.com
- Project placeholders
- Publications & presentations

No framework or build process is required.
