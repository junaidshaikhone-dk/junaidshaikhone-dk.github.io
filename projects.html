Featured research project

COVID-19 Lung Image Analysis

Medical Imaging · CNN · MATLAB · Machine Learning

Developed and trained a convolutional neural network (CNN) in MATLAB using the COVID-19 Radiography Database to explore automated classification of COVID-19 and healthy/non-COVID lung images.

10,001 Training epochs
78% Classification accuracy
CNN Deep-learning model

Project Highlights

  • Prepared and analyzed medical lung images for CNN-based classification.
  • Developed and trained a convolutional neural network using MATLAB.
  • Trained the model for 10,001 epochs.
  • Achieved approximately 78% classification accuracy on the evaluated dataset.

Research Focus

Explored the intersection of health informatics, medical imaging, and artificial intelligence, with an emphasis on applying deep-learning methods to healthcare image data and evaluating model performance.
